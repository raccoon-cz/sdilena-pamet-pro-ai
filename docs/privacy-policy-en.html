Privacy — Shared Memory for AI

A Chrome extension for sharing one memory between ChatGPT and Claude · Přečíst česky

This extension is designed so that all your data stays exclusively on your computer.

What the extension stores

  • Memories you create yourself (text, category, keywords, profile, "always use" / "sensitive" / active flags).
  • Profiles you create yourself.
  • Your settings (context limits, default profile, etc.).
  • The technical connection status to ChatGPT/Claude (whether permission was granted).

All of this data is stored only via chrome.storage.local — the browser's local storage tied to your profile on this computer.

What the extension does not store or do

  • There is no server operated by the developer. Data is never sent anywhere, never backed up outside your computer, and the developer has no access to it.
  • No telemetry or analytics. The extension does not track how you use it.
  • No reading of passwords or login cookies. The extension has no reason or permission to access them and does not attempt to.
  • No automatic sending of messages. The extension never clicks the Send button in ChatGPT or Claude on its own.
  • No user registration. The extension does not require an account or sign-in.

When data reaches OpenAI or Anthropic

Selected memories become part of a request to ChatGPT or Claude only when:

  • you yourself choose which memories to use (or let the extension suggest a selection, which you review),
  • you yourself click "Insert into query",
  • you yourself send the resulting query using the Send button in that service.

Without this explicit action on your part, no memory is ever sent anywhere.

What deleting data does not affect

Deleting memories, profiles, or wiping all data in this extension does not remove messages you have already sent to your ChatGPT or Claude history — those are managed by those services themselves, outside this extension.

Permissions

The extension does not request access to ChatGPT or Claude until you click "Connect" in the "Connected AI" section. You can revoke access to a domain at any time using the "Disconnect" button, without deleting your saved memories.
